<summary><h2>🔄 How I Ship: CI/CD & GitOps (click to expand)</h2></summary>

```
GITHUB → GIT → JENKINS ─┬─ BUILD
                         └─ TEST
                              │
                              ▼
                           DOCKER
                              │
                              ▼
                         KUBERNETES
                              │
                              ▼
                           GITOPS
                              │
                              ▼
                         PRODUCTION
```

Every change flows through source control, automated build/test, containerization, and Git-driven deployment — so production always reflects what's in the repo.

</details>

<details>
<summary><h2>📈 Monitoring & Observability (click to expand)</h2></summary>

```
Applications ──┐
Infrastructure ┤──▶ Metrics ──▶ Prometheus ──▶ Grafana ──▶ Alerts ──▶ Troubleshoot ──▶ Improve
```

Metrics from apps and infra feed into Prometheus, visualized in Grafana, driving alerting and continuous improvement loops.

</details>
